## Projeto em destaque

### [Endpoint Provisioning Kit](https://github.com/henriquegbianchini/Endpoint_Provisioning_Kit)

Projeto pessoal em **PowerShell** para preparar, validar e auditar endpoints Windows.

- **Entrega:** um template modular que reúne inventário, validação de configuração, auditoria e fluxos opcionais de provisionamento.
- **Evidências:** execução em modo de simulação (*dry run*), verificações estáticas e exemplos públicos de relatórios [TXT](https://github.com/henriquegbianchini/Endpoint_Provisioning_Kit/blob/main/docs/reports/WORKGROUP_LAB_DRYRUN_20250514_103015.txt) e [HTML](https://github.com/henriquegbianchini/Endpoint_Provisioning_Kit/blob/main/docs/reports/WORKGROUP_LAB_DRYRUN_20250514_103015.html).
- **Implementação:** scripts PowerShell, configuração por arquivos JSON, validação de hashes SHA-256, logs, backups e autorização explícita para operações sensíveis.

O repositório utiliza configurações genéricas de laboratório e não expõe credenciais ou dados de ambientes corporativos. Os exemplos demonstram as funcionalidades do projeto; não representam métricas de produtividade em produção.
