## Projeto em destaque

### [Endpoint Provisioning Kit](https://github.com/henriquegbianchini/Endpoint_Provisioning_Kit)

Projeto pessoal em **PowerShell** para validação, inventário, auditoria e preparação opcional de endpoints Windows.

- **O que entrega:** inventário de hardware, verificações de sistema e configuração, auditoria de domínio/workgroup e relatórios técnicos.
- **Como foi desenvolvido:** módulos PowerShell, configuração por JSON, integridade de instaladores via SHA-256 e autorização explícita para operações sensíveis.
- **Como verificar:** documentação, capturas de execução simulada, relatórios de exemplo e testes estáticos no repositório.

As evidências públicas usam dados simulados de laboratório. O projeto não é apresentado como uma ferramenta de SOC nem como solução comprovada em produção.

## Formação e laboratório

Cursando **Redes de Computadores no Senac São Paulo**. Mantenho um laboratório pessoal com Linux/Debian e serviços de rede para aprofundar conhecimentos em administração de sistemas, segurança e controle de acesso.
